## 01 / Keep it awake

### [Never Sleep](https://github.com/AhmedRoza/NeverSleep)

Keep Windows awake while you need it. Choose a timer, keep the screen on if you want, and control it from the system tray.

خلّي الجهاز صاحي وقت ما تحتاجه. حدّد المدة، واختار لو عاوز الشاشة تفضل شغالة، وتحكّم فيه من جنب الساعة.

**Go · WebView2 · Windows**

[Download v2.0.0 ↗](https://github.com/AhmedRoza/NeverSleep/releases/tag/v2.0.0) · [Source & details](https://github.com/AhmedRoza/NeverSleep)

<sub>Designed to prevent idle sleep, not bypass lid-close, lock-screen or Windows security policies. Checked on a Windows VM, not a physical laptop. Full limits are in the project README.</sub>

## 02 / Make it yours

### [إيقونة / Eqona](https://github.com/AhmedRoza/Eqona)

Give folders their own look. Create or change folder icons from images, with an Arabic and English interface.

خلّي لكل فولدر شكله. اعمل أيقونة من صورة أو غيّر أيقونة فولدر موجود، بواجهة عربي وإنجليزي.

**C# · WinForms · Windows**

[Explore the project ↗](https://github.com/AhmedRoza/Eqona)

<sub>Supports ICO, PNG, JPG/JPEG and static WEBP inputs. Native Windows Explorer behavior is not fully verified. Requirements and compatibility limits are in the project README.</sub>
